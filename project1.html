AUTOMATED PLANT WATERING SYSTEM

Project Overview

This project is an IoT-based automated plant watering system designed to monitor soil conditions and automate irrigation using a microcontroller, soil moisture sensor, relay module, and water pump.

The system processes real-time sensor readings to determine when watering is needed and integrates the Blynk platform for wireless monitoring and remote system control.

GitHub Repository

Key Features

  • Automated irrigation based on real-time soil moisture readings
  • Threshold-based pump activation and shutdown control
  • Remote pump control through the Blynk IoT platform
  • Real-time monitoring of moisture levels and system status
  • LED and buzzer indicators for hardware feedback and system alerts
  • Mobile notifications for watering events and system updates

Tools & Components Used

Hardware

  • Capacitive Soil Moisture Sensor
  • 5V Water Pump (externally powered)

Software

  • Arduino IDE

How It Works

The capacitive soil moisture sensor continuously measures soil conditions and sends readings to the Arduino microcontroller for processing.

The Arduino compares sensor values against predefined moisture thresholds and controls the relay module to activate or deactivate the water pump when irrigation is required.

System status and sensor data are communicated through the Blynk IoT platform, enabling remote monitoring and manual control of the system.

Challenges & Solutions

Pump required more power than the microcontroller could provide
Solution: Used an external 5V power source and relay module to safely control the pump.

Unstable sensor readings during testing
Solution: Improved wiring connections and adjusted sensor handling to achieve more reliable readings.

Pump switching behavior required refinement
Solution: Implemented threshold adjustments in the control logic to improve automated watering behavior.

Hardware integration and debugging issues
Solution: Tested individual components, verified connections, and iterated on the system design.
